# DPEG Task Manager — Employee Quick Start Guide

Use the **Tasks** page to receive work, assign work, communicate, submit proof, and review completed tasks.

## My Tasks

This section contains tasks that someone assigned to you.

1. Select the person’s name to see their tasks.
2. Select a task to view its details.
3. Change **Assigned** to **In Progress** when you begin working.
4. Use **Messages** if you have a question or need to provide an update.
5. When the work is finished, select **Submit Proof**.

Indicators beside a task tell you when you have a new message, reminder, or requested change.

## Assigned by Me

This section contains tasks you assigned to other employees.

1. Select the employee’s name to see their tasks.
2. Use **Messages** to ask a question or provide instructions.
3. Use **Remind** to send a simple reminder without writing a message.
4. When proof is submitted, select **View Proof**.
5. Approve acceptable proof or request changes when more work is required.

## Messages

Each task has one shared conversation between the assignor and assignee.

- Use Messages for questions, instructions, updates, or explanations.
- New activity displays **1 unread**.
- Opening Messages marks the conversation as read.
- Type your message in the box at the bottom, then select **Send**.

Keep all discussion about a task inside that task’s Messages conversation.

> **When sending a message:** Select **Send** once and wait until your message appears in the conversation before sending another message. Do not double-click Send. If another person is actively replying, allow their message to appear before continuing.

## Submit Proof

Submit proof only after completing the task.

1. Select **Submit Proof**.
2. Describe what was completed.
3. Attach supporting files, photographs, or documents when needed.
4. Select **Submit Proof** once.

After submission, the form closes and displays **Proof sent**. Use Messages for any additional information. If changes are requested, select **Resubmit Proof** after correcting the work.

## Reminder

Reminder is a quick nudge from the person who assigned the task.

- The assignor can select **Remind** more than once when necessary.
- The assignee sees the reminder count beside the affected task.
- A reminder does not replace a detailed message. Use Messages when an explanation is needed.

## History

History contains completed and cancelled tasks.

- History is for reference only.
- It shows whether proof was submitted, the number of messages, and reminder history.
- Historical labels are not actions and cannot be changed.

## Remember

- **My Tasks** = work I need to complete.
- **Assigned by Me** = work I gave to someone else.
- **Messages** = questions, instructions, and updates.
- **Submit Proof** = evidence that the work is complete.
- **Reminder** = a quick nudge.
- **History** = completed or cancelled records.

If something does not work, take a screenshot and report the task name, approximate time, and whether you were using a phone or computer.
